# Segurança da prévia local

Não há conexão com banco externo. O armazenamento do navegador permite apenas conferir e editar a prévia neste aparelho.
Os controles de acesso da interface não oferecem autenticação para produção.
Antes de publicar com o novo banco, implementar autenticação real e permissões de acesso para produtos, pedidos, clientes e administração.
